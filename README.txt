NEXORA DIGITAL LANDING PAGE

Files
- index.html: responsive, single-file landing website (HTML, CSS, JavaScript)

Run locally
- Double-click index.html, or open it in a browser.

Before publishing
1. Open index.html and find BUSINESS_EMAIL near the bottom.
2. Replace REPLACE_WITH_YOUR_BUSINESS_EMAIL with the real inbox for project enquiries.
3. Review the selected demo links in the portfolio section and replace/add links as needed.
4. Check the wording and service scope before publishing.

Deployment
- GitHub Pages: upload index.html to the root of a repository and enable Pages in repository Settings.
- Any static hosting provider: upload index.html as the site entry point.

The contact form uses mailto and opens the visitor's email app; it does not store submissions on a server.
